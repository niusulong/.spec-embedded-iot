# ASR1603 分析方法（仅差异）

> 平台：ASR1603（ARM Cortex-R + ThreadX）。本文件只列与通用基线的差异，通用方法见 `SKILL.md` 与 `references/analysis-patterns.md`。

## 根注解
ARM Cortex-R + ThreadX + PSRAM/DDR 代码执行区。下面的 tx_thread / DataAbort / PSRAM 差异源于此——**Cortex-R 异常模型（DataAbort 访存异常）+ PSRAM 区跑代码**是 ASR 平台的核心特征。

## 平台专属问题模式（仅本平台特有，通用 8 模式不重复）
| 现象 | 日志特征 | 根因方向 |
|------|----------|----------|
| DataAbort | `DataAbort`、访问非法地址 | 野指针 / 释放后使用 / PSRAM 数据损坏 |
| PSRAM 代码完整性失败 | PSRAM 区执行校验异常 | DDR/PSRAM 数据被踩 / 时序问题 |
| ThreadX 阻塞 | `tx_thread` 长时间挂起 | 信号量/队列等待未唤醒、优先级反转 |
| 看门狗超时 | `WDT`、`WdTimeout` | ISR 或线程死循环、调度被阻塞 |

> 本平台暂无"差异化定位手法"积累，诊断时以通用手法（时间戳间隔统计 / count 驱动批量识别等）为主。
