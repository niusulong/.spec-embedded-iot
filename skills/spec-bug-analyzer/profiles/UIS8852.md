# UIS8852 分析方法（仅差异）

> 平台：UIS8852（Unisoc RISC-V RV32 + RT-Thread）。本文件只列与通用基线的差异，通用方法见 `SKILL.md` 与 `references/analysis-patterns.md`。
> 结构契约见 `_schema.md`。

## 根注解
RISC-V RV32 + RT-Thread（**非 ARM、非 FreeRTOS**）。任务模型与日志串与 ARM/FreeRTOS 平台不同，识别日志时注意区分。

## 日志差异
- 任务/线程名是 `rt_thread`（非 FreeRTOS 的 `xTask`）；线程库相关串 `g_osAssert` / `g_osException`
- 当前中断号日志字段为 `g_osIrqNo`
