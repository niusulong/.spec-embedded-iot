### 6.x 结论确定性分级（必填，避免过度推断）
对根因结论显式标注确定性（对抗审查教训：勿把机制具体化到 dump 无法支撑的精度）：
- **铁证**（dump 直接证明、可复核）：崩溃指令 PC/LR、寄存器值、反汇编、链表损坏节点、堆坏块。
- **合理推测**（强证据支撑的根因域，但非唯一）：如"X 模块生命周期缺陷→堆损坏"。
- **待验证**（静态 dump 无法唯一确定）：如"哪条释放路径产生悬空节点"——给出复测方法（埋点/染色）。
> HardFault 场景：FreeRTOS 正常删除"先摘链后释放"，单次删除不残留悬空节点；链表损坏根因多为
> 并发 double-free / use-after-free / 越界写（间接堆损坏）。区分"已损坏"（铁证）与"成因路径"（待验证）。
